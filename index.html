Network Router Packet Inspector

A network router inspects incoming binary packet headers over alphabet Σ = {0, 1}. A packet is forwarded only if its header begins with the prefix 101. Otherwise, it is routed to dead state qd and discarded.

5-Tuple Formal Definition

The automaton is defined formally as M = (Q, Σ, δ, q₀, F):

  • Q (States) = { q0, q1, q2, q3, qd }
  • Σ (Alphabet) = { 0, 1 }
  • q₀ (Start State) = q0
  • F (Final States) = { q3 }
  • Language L(M) = { w ∈ {0,1}* | w = 101x, x ∈ {0,1}* }
